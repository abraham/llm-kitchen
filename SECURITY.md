# Security

Please report security problems privately, through
[GitHub's private vulnerability reporting](https://github.com/abraham/llm-kitchen/security/advisories/new),
not in a public issue or pull request.

In scope: the site at https://llm.kitchen, the code and recorded data in this repository, and its
GitHub Actions workflows and deploys. Models and files served by Hugging Face, and the browsers that
run them, are out of scope; report those to their owners.

Only the live site and the `main` branch are supported. What the site defends against, and how, is
in [docs/spec/security.md](docs/spec/security.md).
